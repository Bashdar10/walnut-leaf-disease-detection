About the Project

Walnut Leaf Disease Detection is a university final project using a Flask API and a trained PyTorch {{ model_name }} model.

Project Overview

The goal of this system is to help identify walnut leaf diseases from uploaded or camera-captured images. The application provides the predicted class, confidence score, management recommendation, downloadable result, and prediction history.

The web application is designed with a calm academic dashboard style suitable for demonstrations to professors, classmates, and project evaluators.
